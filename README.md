# AI Programming Tutor

基于大语言模型的渐进式编程学习与知识诊断系统。

## 项目介绍

本项目旨在设计一个面向编程学习者的 AI 辅助学习系统。

不同于传统 AI 编程助手直接生成答案，
本系统通过代码分析、错误诊断和渐进式 Hint 引导学生自主解决问题。

## 核心功能

- 编程题输入
- 学生代码提交
- AI代码诊断
- 错误类型分析
- 分级 Hint 引导
- 学习记录保存
- 知识薄弱点统计

## 技术路线

- Python
- Streamlit（Web交互界面）
- Large Language Model API（AI代码分析）
- Prompt Engineering（渐进式Hint设计）
- JSON / SQLite（学习记录存储）

## 项目目标

帮助学生提高编程理解能力，
而不是简单替代学生完成代码。
